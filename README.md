# Project14_1 - Категории и товары

## Описание
Проект реализует классы `Product` и `Category` для управления товарами и категориями.

## Установка и запуск

### Требования
- Python 3.10+
- Poetry

### Установка зависимостей

poetry install

### Запуск тестов

poetry run pytest -v

### Проверка покрытия

poetry run pytest --cov=src --cov-report=term
